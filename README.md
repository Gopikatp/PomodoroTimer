# Pomodoro Timer Website

A simple and interactive productivity website built using HTML, CSS, and JavaScript. This project includes a Pomodoro Timer, To-Do List, About Us page, and Contact Us page to help users manage time effectively and stay organized.

## Features

* Focus Timer (25 minutes)
* Short Break Timer (5 minutes)
* Long Break Timer (10 minutes)
* Start, Reset, and Skip Break options
* Simple To-Do List
* Responsive and attractive UI
* About Us and Contact Us pages

## Technologies Used

* HTML
* CSS
* JavaScript

## How to Run

1. Download or clone the project.
2. Place all files in the same folder.
3. Add the background image as `timer.jpg`.
4. Open `index.html` in a web browser.

## Purpose

This project is designed to improve productivity using the Pomodoro Technique by helping users focus on tasks with timed work sessions and breaks.
